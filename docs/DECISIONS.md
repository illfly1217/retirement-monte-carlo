# 架構與研究決策（2026-10-17）

最新決策（v1.3）：主要開發與版本控制採 Codex＋公開 GitHub，網站採手動發布的 GitHub Pages。MSCI 歷史月資料已取得並在本地實算；公開程式只保存兩項模型參數、樣本定義、方法及來源摘要，不包含原始月序列。資料來源與使用條件查核見 [MSCI_PARAMETER_RESEARCH](MSCI_PARAMETER_RESEARCH.md)。

- 將「參數來源」與「報酬生成方法」分開。MSCI 歷史估計及 VCMM 都可直接搭配參數模型；完整股票月份重抽不阻擋內建參數情境。
- 介面及 Worker 共用 scenarios.js 正規化內建參數；畫面四捨五入供閱讀，運算及匯出保留完整精度。VCMM 的波動、區域權重及長期銜接明標專案假設。
- 內建數值持續可見、灰色唯讀；只有自訂可編輯，並分開保存自訂草稿。CPI 顯示樣本摘要但仍實際逐月抽樣；固定通膨的波動標為不適用。
- 預設採 MSCI 歷史估計與幣種固定通膨假設。舊版自訂值保留；不把 7%／18% 自訂預設冒充歷史實算。

下列為較早決策的歷史紀錄；其中要求訪客匯入 CSV 或表示 MSCI 資料尚未取得的部分已由上述決策取代。

1. **Buildless ES Modules＋Web Worker**：GitHub Pages 靜態 hosting 相容；正式網站沒有運算伺服器或第三方 runtime。Playwright 僅為開發測試依賴。測試與正式網頁共用純計算引擎，不建立平行的示範版引擎。
2. **資料誠實優先**：沒有合法MSCI數列就清楚顯示未載入，歷史模型不偷偷fallback。第一開啟採可用的自訂CAGR模型，歷史模式等待使用者合法CSV。這是相較原需求「預設MSCI」的明確限制。
3. **Stationary Bootstrap預設24月**：隨機區塊長度保留局部時間結構，與CPI共用索引；24月是可調敏感度參數，未聲稱從資料估出最適值。IID是比較基準。
4. **年初提領**：便於比對退休文獻、手算及清楚定義現金流。月資料用來生成年度複合回報，提領規則每年評估；未主張逐月現金流模擬。
5. **歷史均值＋對數漂移情境**：CAGR及費用定義分離；無歷史資料時使用明標參數模型。VCMM只有公開部分預測，採具日期、來源與銜接的參考情境，不宣稱專有引擎重現。
6. **生活費與資產雙指標**：單看存續會誤導對比例／護欄策略的理解。預設提領率探索要求各年實質支出≥初始80%且未耗盡。
7. **網格搜尋**：動態規則非嚴格單調，使用0.1百分點網格及共同隨機數，顯示逐點Wilson下限與範圍上界，避免二分搜尋保證假象。
8. **路徑快取**：重用同一市場矩陣比較策略、提領率；取消直接terminate Worker。主執行緒只接收摘要而非100k條全路徑。
9. **資料本機保存**：IndexedDB保存使用者CSV，localStorage保存參數。無CSV上傳API；原始數列不寫入Git、Pages 封裝或匯出研究快照。
10. **版本保存與發布分離**：原 bundle 歷史已恢復，公開 GitHub 是唯一主要版本來源；main push 與 PR 自動執行 CI。Pages 僅手動觸發，選 publish、通過檢查後才可部署 dist/。原先須先本機確認；使用者後續要求透過 GitHub.io 觀看，已依此啟用並成功公開，後續仍手動發布。既有 Sites 受眾保持私人，本次不操作，不採雙來源同步。
11. **完整子路徑回歸**：預覽支援 BASE_PATH，CI 在 /retirement-monte-carlo/ 真正啟動 Chromium，驗證相對資源、ES Modules、module Worker 與主要操作。
12. **系統字型**：移除外部字型下載；產品的文字及 SVG 由本機資源與系統字型呈現，不需第三方請求。
13. **數值失效明示**：CSV 水準換算及跨年累積超出 Float64 可用範圍時拒絕結果，不將 NaN／Infinity 畫成研究結論。快取命中仍驗證全部設定。

公開網站前仍需使用者試用確認及第三方引用方式確認，詳見 THIRD_PARTY_NOTICES。未納入債券、稅務及外幣模組；擴充須維持市場月份向量與現金流邊界。
