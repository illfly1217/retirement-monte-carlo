# 架構與研究決策（2026-10-17）

開工階段先確認Sites可建立private Site，GitHub連線可讀但無建立repo操作，CLI憑證失效。MSCI未取得可重分發完整月序列。第一版以正確可用的瀏覽器運算工具為範圍。

1. **Buildless ES Modules＋Web Worker**：Sites靜態hosting相容，沒有長期運算伺服器或套件供應鏈。測試與正式網頁共用純計算引擎，不建立平行的示範版引擎。
2. **資料誠實優先**：沒有合法MSCI數列就清楚顯示未載入，歷史模型不偷偷fallback。第一開啟採可用的自訂CAGR模型，歷史模式等待使用者合法CSV。這是相較原需求「預設MSCI」的明確限制。
3. **Stationary Bootstrap預設24月**：隨機區塊長度保留局部時間結構，與CPI共用索引；24月是可調敏感度參數，未聲稱從資料估出最適值。IID是比較基準。
4. **年初提領**：便於比對退休文獻、手算及清楚定義現金流。月資料用來生成年度複合回報，提領規則每年評估；未主張逐月現金流模擬。
5. **歷史均值＋對數漂移情境**：CAGR及費用定義分離；無歷史資料時使用明標參數模型。VCMM只有公開部分預測，採具日期、來源與銜接的參考情境，不宣稱專有引擎重現。
6. **生活費與資產雙指標**：單看存續會誤導對比例／護欄策略的理解。預設提領率探索要求各年實質支出≥初始80%且未耗盡。
7. **網格搜尋**：動態規則非嚴格單調，使用0.1百分點網格及共同隨機數，顯示逐點Wilson下限與範圍上界，避免二分搜尋保證假象。
8. **路徑快取**：重用同一市場矩陣比較策略、提領率；取消直接terminate Worker。主執行緒只接收摘要而非100k條全路徑。
9. **資料本機保存**：IndexedDB保存使用者CSV，localStorage保存參數。無CSV上傳API；原始數列不寫入Git、Site封裝或匯出研究快照。
10. **版本保存**：目標是Sites來源Git持久保存；本次命令環境網路限制導致推送尚未成功，因此先保存本機Git及交付專案包，不宣稱已同步。GitHub可用後新增獨立remote並採明確雙向整合與同SHA發布，無自動同步假設。固定`.openai/hosting.json` project_id以保留同網址，維持owner-private。

公開前待解：MSCI及其他第三方數據的再散布／呈現權利、GitHub repo建立、使用者對方法和參數的實際試用。與本版研究範圍無關的債券／稅務模組不混入引擎。
