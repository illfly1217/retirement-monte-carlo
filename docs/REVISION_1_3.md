# v1.3：內建參數與可見的唯讀設定

## Issue #4：本地校準，網站只帶參數

已經由 MSCI 官方查詢頁下載並核對 ACWI IMI 664204、USD、Net、Monthly。357 筆月末水準為 1997-01-31–2026-09-30，產生 1997-02–2026-09 的 356 個連續月報酬。沒有將 factsheet 的 1994 起日冒充本次下載期間。原檔與 CSV 留在已忽略的 local-data/msci/。

scripts/calibrate-equity.mjs 使用現有統計定義，產生只有報酬、對數波動、來源、期間、方法、版本與雜湊的摘要。引擎新增 msci 參數來源，與 historical 月份重抽模式分開，無需公開整段月資料。畫面為 7.89%／15.97%，模擬與匯出保留未四捨五入的實算值。

來源、逐項交叉核對及使用條件查核見 [MSCI_PARAMETER_RESEARCH](MSCI_PARAMETER_RESEARCH.md)。資料可取得、參數可計算，不代表取得原始序列再散布或個別服務授權；相關紀錄保留於摘要，不以尚未確定的法律解釋阻擋功能實作。

## Issue #7：內建灰色唯讀，自訂可編輯

MSCI、VCMM 及固定通膨預設都會帶入實際使用設定並持續顯示。VCMM 的 18% 波動、63% 美股權重、長期 7% 及十年銜接均明標本工具研究假設，非官方完整引擎。CPI 顯示歷史幾何變動／對數波動的樣本摘要，實際仍逐月進行獨立區塊抽樣。固定通膨的波動顯示不適用。

自訂報酬與自訂固定／隨機通膨分別保存草稿，切換及重新整理不被內建值覆蓋。舊版固定通膨保持自訂且可編輯；舊版 VCMM 恢復時採目前版本化預設。介面與 Worker 共用 scenarios.js，不能只改畫面卻用另一組參數運算。

## Issue #8：模型用途與狀態

一般流程明示股票使用參數模型，移除只有一個可選項的抽樣選單。歷史 IID／區塊抽樣列於方法說明，說明單月分布、月份連續性、樣本限制與片段接點。不同方法不是準確度等級；通膨 CPI 抽樣與股票方法分開標示。新增演算法不在本次範圍。

JSON 快照及年度 CSV 記錄實際情境、股票／通膨抽樣方式、參數與版本；CPI 值標為樣本統計，VCMM 保留期限銜接設定。均不輸出原始股票月序列。
